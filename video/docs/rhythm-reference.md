# 节奏参考拆解

样本：抖音电影解说《毒液：最后一舞》，6 分 8 秒，1280×720 横屏。只记统计数据，不保存原视频。

## 镜头
用 ffmpeg `scdet`（阈值 10）切镜头：297 个镜头，平均 1.24 秒，中位 0.97 秒。

| 镜头长度 | 占比 |
|---|---|
| < 1 秒 | 50% |
| 1～2 秒 | 29% |
| 2～3 秒 | 12% |
| 3 秒以上 | 9% |

每 30 秒切几次：13, 11, 28, 25, 29, 17, 22, 18, 41, 33, 38, 20, 6。开头约 2.5 秒一切，4～5 分钟的高潮段接近每秒一切，结尾放慢。

## 字幕
- 每个画面底部居中都有一行字幕，大多不超过 12 个字，1～2 秒换一句。
- 字幕换的时候画面基本也跟着换：一句话配 1～2 个镜头。

## 声音
- 配音加配乐从头到尾不断，用 -40dB 检测找不到 0.25 秒以上的静音。
- 整体响度 -12.8 LUFS，是短视频平台常见的偏响的音量。

## 对我们的结论
财经视频照抄电影解说那么快不现实，图表要时间看。做法：实拍镜头按解说节奏切（约 1 秒），图表画面用「每秒一个新动作」代替切镜头。
