# Audio implementation plan

**Goal:** Implement Issue #2 without changing the default video workflow.
**Architecture:** Keep the source-module protocol, add optional `search_audio(query, limit)` and audio metadata (`media`, `audio_url`, `preview_url`, `kind`). Resolve by source ID and current upstream metadata. Keep the existing license schema; expose `commercial_ok` on audio/voice results as well. Audio processing uses ffmpeg; voice providers live separately and edge-tts remains optional.
**Constraints:** No scraping, Freesound OAuth2, local voice models, cloning, video refactor, or merge. No keys committed. Freesound/Jamendo live checks skipped if absent from ai-vault.

Extend Commons, Archive (retain license filter), NASA. Record JSON fixtures with provenance, test parsing and rights including unknown/NC licenses.

Resolve audio, inspect full waveform PNG + first 15 seconds mp3, trim mp3, preserve shared manifest/credits/note. Library supplies media for legacy video entries. Test source skipping, filtering, media paths and real local ffmpeg output.
- [x] Voices: provider registry with optional edge-tts, `voice_list(lang="zh-CN")`, `voice_preview(voice_id, text)`, explicit noncommercial/unclear license notice. Record voice-list JSON; test listing, missing dependency, dispatch, preview output and failure cleanup.
- [x] CLI/MCP: expose audio flag, waveform response, voices and voice-preview. Keep video inspect JPEG and video CLI defaults. Test adapters and tool schemas.
- [x] README: Chinese/English audio sections, source/key/commercial tables and runnable examples. Run full pytest and build.
- [x] Live acceptance: run the exact audio search, inspect a returned audio, trim from 5s for 10s into /tmp/fm-test and probe duration/manifest/credits; list zh-CN voices and preview Chinese text. Record command summaries and any failures honestly for the PR.
