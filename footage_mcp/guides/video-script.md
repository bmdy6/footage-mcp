# 知识类短视频：选题、文稿和画面

这份指南给写稿的 Agent 和人看。它来自对一条表现很好的知识解说视频的逐秒拆解（抖音「AI 剪一期视频到底多少钱」，4 分 21 秒，2026-11-23），以及 footage-mcp `video/` 样片的实践。

整个流程里，人只做三件事：定选题、改文稿、看成片。素材、配音、画面、质检都交给 AI。

## 1. 选题：一个人人好奇、答案反常识的具体问题

- 能用一句话问出来，最好带数字：「到底花多少钱」「为什么有 50 个模型」。
- 答案要和大家的直觉相反：「不到 20 块」「其实一半是给机器人和配音用的」。
- 你手上要有别人没有的东西：自己的真实数据、亲手试过的结果、整理过的一手资料。
- 先用搜索看看有没有需求：同类视频的播放量、评论区里大家在问什么。

## 2. 文稿结构（3～5 分钟）

| 段落 | 做什么 | 例子 |
|---|---|---|
| 开头 0～6 秒 | 先拿证据，不讲道理。真实战绩、截图、一个惊人的数字 | 「最近一个月 AI 全自动发了 104 条视频」，配后台截图 |
| 自证 | 证明你有资格讲这件事；本片就是作品最好 | 「这期视频也是全自动剪的」 |
| 抛悬念 | 把观众心里的猜测说出来，划掉，再抛出一个问号 | 「Token 是不是烧飞了？——完全不是」→「一期到底多少钱？¥??」 |
| 分章拆解 | 3～5 章，每章开头一张章节卡，每章给一个数字 | 账号订阅、云端渲染、声音字幕… |
| 进度条 | 画面上始终有一个随章节变化的累计值，让观众知道看到哪了 | 顶部「累计 ¥12.8 → ¥18.9」 |
| 揭晓 | 把各章数字汇总，像收银小票一样逐行列出 | 「不到 20 块」 |
| 对比 | 拿一个大家熟悉的参照物来对比，制造冲击 | 外包 700～1000 元 vs 不到 20 块 |
| 回应质疑 | 主动说出观众最可能的反驳，再顺势讲出真正的门槛 | 「你不就是靠 Claude Code 吗？」→ 差距在经验和审美 |
| 适合谁 | 分几类人，让每个观众对号入座 | 想转型的剪辑师、老板、工作室、个人博主 |

## 3. 句子怎么写

- 一句不超过 12 个字。一句话就是一行字幕，也是一个画面动作，写的时候就想好这句配什么画面。
- 每个数字都写清来源和日期；查不到就写「未取得」，片子里会自动显示。
- 算式直接写出来，让观众自己能算：「$200 ≈ ¥1,334，除以 104 条，每期 ¥12.8」。
- 少用形容词，多用数字和对比。

## 4. 画面

- **讲自己的事，就用自己的真东西**：后台截图、录屏、代码、成片。素材库的镜头只当补充。
- **讲外部的事，用一手资料**：官方页面截图、发布时间线、价格表。
- **节奏靠「冒元素」，不靠快切**：每句配音配一个新动作，比如大字跳出、数字滚动、卡片飞入、错误答案被划掉。
- 底部全程字幕，配音和配乐不间断。
- 配色和规则见仓库里的 `video/STYLE.md`。

## 5. 交付前自查

- [ ] 开头 6 秒里有没有一个具体的数字或证据？
- [ ] 有没有一个悬念，让观众要看到最后？
- [ ] 每个数字都有来源和日期吗？
- [ ] 有没有说出观众最可能的反驳？
- [ ] 每一句都想好配什么画面了吗？
- [ ] 成片跑过 `npm run qa`，没有黑屏和闪帧？
